## What am I looking at?

Shaded regions are **forbidden**: physics rules them out (faster than light, below one quantum, denser than a black hole, louder than a vacuum allows). Dotted and dashed lines are **practical limits** where a class of object fails, such as material strength, self-gravity or the speed of sound. Markers are **real objects**, each with a source: the bar spans the known range of its class, and a black cap marks that object's own maximum.

## Interactive website

[`site/`](site/) is a Vue 3 + Vite + TypeScript app that draws every chart with [Observable Plot](https://observablehq.com/plot/):
- Hover or tap any object for its value, notes and source.
- Toggle categories on and off.
- Read each chart's explainer.
- Download the data or the print figures.
- Switch the interface between English, Korean (한국어) and Urdu (اردو, right-to-left). Links can carry the language, e.g. `?lang=ko`. Strings and translated chart titles live in [`site/src/i18n/messages.ts`](site/src/i18n/messages.ts); chart content (axes, lines, objects, explainers) stays in English.

It reads only the JSON that `make figures` exports to `site/public/`, so the limit lines on the website are the same sampled formulas as in the PNGs. It works on phones down to 375 px.

```bash
make figures   # Python: data -> figures + site/public/data
make site      # npm ci + production build into site/dist
make dev       # local dev server
```

GitHub Pages deploys it from [`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every push to `main`, after lint and tests pass, to <https://quantumnovice.github.io/awesome-universal-limits/>. One-time setup in a fork: **Settings → Pages → Source: GitHub Actions**. Hash routes are shareable (`#/chart/spin`), and `site/public/404.html` redirects path-style links such as `/chart/spin` to them.

## Quick start

```bash
uv sync
make figures   # schemas, data/json, figures/, site data, docs/REFERENCES.md, this README's gallery
make test      # limits vs hand-computed values, data validation, bounds, label overlaps
make sources   # check every DOI against Crossref and every URL (needs network)
```

Without `make` or `uv`, use `python -m allowed_universe.build` and `python -m pytest` with `src/` on `PYTHONPATH`.

## How to add an object

Add one row to the right CSV in [`data/`](data/) with a primary source in `source_url` and a short `citation`, then run `make figures test`. Use SI units, and give the class range (lowest to highest) rather than one cherry-picked value. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Data and sources

- **Datasets.** 34 charts are drawn from 35 CSV files in [`data/`](data/). Each is validated against a JSON Schema in [`data/schema/`](data/schema/) and exported to [`data/json/`](data/json/) with column descriptions.
- **Sources.** Every row has a `source_url` and `citation`. Every limit line that uses a measured constant cites its source too. All of them are collected in [docs/REFERENCES.md](docs/REFERENCES.md) and [docs/references.bib](docs/references.bib). Journal sources are DOIs, and `make sources` confirms each DOI resolves to the cited title.
- **Limit lines are computed, never hand-drawn.** They come from pure functions in [`src/allowed_universe/limits.py`](src/allowed_universe/limits.py) using CODATA 2022 constants from `scipy.constants`. Each one is unit-tested against a hand-computed value.
- **Tests enforce the bounds.** A test fails if any object crosses a hard bound on its chart.

## How to cite

See [CITATION.cff](CITATION.cff). When you reuse a specific number, please also cite its primary source from `docs/REFERENCES.md`.
